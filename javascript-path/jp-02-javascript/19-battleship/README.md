**_DESCRIPTION_**: This repo contains a classic Battleship game built using vanilla JavaScript. The core game mechanics handle matrix grids and rules entirely independent from user interface. I also put extra effort into computer AI, so it tracks down ships instead of just shooting blindly. And visual preview of the ships after being sunk

## Live Preview

The live site can be viewed [**here**](https://odin-19.vercel.app).

## Setup

This app uses webpack packages. To run this setup locally:

```bash
npm install
npm run build
npx serve dist
```

After that, just head to [localhost:3000](http://localhost:3000) to see the app running.
