**_DESCRIPTION_**: This repo contains a memory card game built with React as a practice project for hooks, state management and side effects. Selecting a card that hasn't been clicked before increases the score, while clicking the same card twice resets the run and keeps the best score reached so far.

## Live Preview

The live site can be viewed [**here**](https://odin-22.vercel.app).

## Setup

This app uses Vite. To run this setup locally:

```bash
npm install
npm run build
npx serve dist
```

After that, just head to [localhost:3000](http://localhost:3000) to see the app running.
